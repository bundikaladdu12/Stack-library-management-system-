STACKS — Library Management System

Files:
- index.html: app structure
- style.css: responsive styling
- script.js: linked list, FIFO queue, stack and interactions

IMPORTANT (Android): If opening a local HTML file shows the page but taps do nothing, your file viewer may be using a restricted preview. Extract this ZIP fully, then either open index.html in Chrome using a file manager that launches Chrome, or deploy the folder to GitHub Pages/Vercel and use the HTTPS URL. Do not open index.html inside a document preview.

This is a static demo. Data is stored in this browser/device only.
